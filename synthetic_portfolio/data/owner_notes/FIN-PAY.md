# FIN-PAY - Payroll API

Last updated: 2026-10-18

Interview with Sofia Castell.

Payroll handles employee bank details and stores card numbers for corporate card reimbursements, so it is in PCI scope. Security has asked for a review before any move, but nobody has scheduled it yet. Payroll runs on the 15th and the last business day of each month; avoid the three days before each run.
