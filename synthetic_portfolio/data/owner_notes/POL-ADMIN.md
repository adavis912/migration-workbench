# POL-ADMIN - Policy Administration (COTS)

Last updated: 2026-09-14

Interview with Felix Ellison, policy systems lead.

Vendor COTS suite on Tuxedo. App servers run Oracle Linux 7 and the vendor only certifies Oracle Linux, so we cannot change the OS without their sign-off. The Rating Engine shares our Exadata database, using the same schemas. Renewal season freeze: March 25 to April 15.
